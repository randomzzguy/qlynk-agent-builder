# Qlynk Agent Builder

Build accurate, client-owned Qlynk Agents with a guided interview, verified knowledge mapping, launch testing, and handoff workflow.

## Use in Codex

Invoke the installed skill with:

```text
Use $build-qlynk-agent to build a Qlynk Agent for my client.
```

## Use in Claude Code

Invoke the installed plugin skill with:

```text
/qlynk-agent-builder:build-qlynk-agent
```

Claude can also load the skill automatically when asked to build, test, improve, or hand off a Qlynk Agent.
